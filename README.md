# Практическое задание 3Б. Справочник пользователей

## Запуск приложения

1. Распаковать архив с файлами.
2. Открыть файл `index.html` в браузере.

Серверная часть и база данных не требуются.

## Реализованные функции

- Загрузка списка пользователей из `https://jsonplaceholder.typicode.com/users`.
- Отображение имени, email и города каждого пользователя.
- Поиск по имени без повторного запроса к серверу.
- Поиск не учитывает регистр.
- Если совпадений нет, выводится сообщение «Пользователи не найдены».
- Для каждого пользователя есть кнопка «Показать публикации».
- По нажатию на кнопку загружаются публикации пользователя с `https://jsonplaceholder.typicode.com/posts?userId=ID`.
- Выводятся заголовки и тексты первых трёх публикаций.
- Во время запросов показывается состояние загрузки.
- Кнопка «Загрузить пользователей» отключается во время загрузки и включается после завершения запроса.
- Ошибки HTTP и сетевые сбои обрабатываются через `response.ok`, `try`, `catch`, `finally`.
- После ошибки можно повторно выполнить запрос.

## Результаты проверки

- Нажатие кнопки «Загрузить пользователей» загружает 10 пользователей.
- Поиск `Leanne` оставляет только подходящую запись.
- Поиск неизвестного имени показывает сообщение об отсутствии результатов.
- Нажатие кнопки «Показать публикации» выводит первые три публикации выбранного пользователя.
- При временной замене адреса на `/userz` появляется сообщение об ошибке.
- После восстановления правильного адреса повторный запрос работает корректно.
